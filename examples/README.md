# Examples

This folder holds notes from real runs of the playbooks, on public repos or a personal sandbox only. A run note records what happened, so the playbook can be corrected against it.

Name each note `<playbook>_<repo>_<yyyymmdd>.md`, for example `refactoring_some-oss-repo_20261201.md`.

A run note has five lines:

- Repo and commit: the public repo and the commit the run started from.
- Task: what you asked the agent to do.
- What worked: steps and prompts that held up.
- What the playbook got wrong: steps that failed, missing pitfalls, prompts you had to change.
- Changes made to the playbook: what you edited afterwards, with the playbook name.
